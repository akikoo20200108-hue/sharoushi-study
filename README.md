# 社労士2027 学習ナビ

アガルート 2026年合格目標 入門総合カリキュラム（フル）の教材を使って、2027年8月の社労士試験に向けた学習計画を回すための進捗管理アプリです。ビルド不要・サーバー不要の静的HTMLです。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面（今日やること／今週／進捗／全体計画／設定） |
| `app.js` | ロジック。進捗・学習記録は `localStorage` に保存 |
| `style.css` | スタイル（ダークモード対応） |
| `plan.js` | 学習計画データ（自動生成。直接編集しない） |
| `gen_plan.py` | `plan.js` と `PLAN.md` を生成するスクリプト |
| `PLAN.md` | 学習計画の読み物版（42週の週別タスク一覧） |

## 使い方

1. `index.html` をブラウザで開くだけで動きます（ダブルクリックでOK）。
2. 「今日やること」で今週のタスクをチェック、下の学習記録に分数を入力して「記録する」。
3. 「進捗」で全体％・フェーズ別・科目別・週別時間を確認。
4. 端末を変えるときは「設定 → JSONをエクスポート」でバックアップ。

## 計画を変えたいとき

`gen_plan.py` の `assign(...)`（科目の週割り）や `add(...)`（タスクと時間）を編集して再実行します。

```powershell
python C:\Users\akiko\projects\sharoushi-study\gen_plan.py
```

※ `gen_plan.py` は自身のあるディレクトリに `plan.js` / `PLAN.md` を書き出すため、`cd C:\Users\akiko\projects\sharoushi-study` してから実行してください（カレントディレクトリに出力する仕様）。

タスクIDは生成順に振られるため、途中にタスクを挿入すると以降のIDがずれてチェック状態が引き継がれません。追加する場合は末尾（該当週の最後）に足すか、追加後に「設定 → 全データを削除」で初期化してください。

## 計画の前提

- 学習期間: 2026-11-01（日）〜 2027-08-21、42週（試験日は例年8月第4日曜＝2027-08-22想定。公式発表で要確認）
- 週10〜15時間（目標12h）。計画上の合計は約430h
- 映像講義は視聴期限切れのため、テキスト＋肢別過去問集＋答練＋模試で進める
- 2026年版テキストは2027年試験の法改正・白書に未対応 → 第34〜35週で2027年版の法改正・白書教材を別途入手して対応
